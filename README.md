##  Sobre o projeto

Este projeto foi desenvolvido para a disciplina de **Sistemas Operacionais**, com o objetivo de explorar, implementar e simular conceitos fundamentais relacionados ao funcionamento interno de um sistema operacional.

A aplicação reúne implementações práticas de algoritmos e mecanismos computacionais, permitindo analisar operações, compreender o gerenciamento de recursos e visualizar, por meio de simulações, conceitos estudados em sala de aula.

##  Objetivos

- Aplicar conceitos teóricos de Sistemas Operacionais na prática.
- Compreender algoritmos utilizados no gerenciamento de recursos.
- Explorar estruturas de dados e técnicas de processamento.
- Desenvolver simulações para facilitar a análise das operações.
- Aprimorar conhecimentos em programação e organização de código.

##  Conhecimentos abordados

O projeto relaciona conceitos fundamentais da área de Sistemas Operacionais com sua implementação em código, contribuindo para o entendimento de algoritmos, gerenciamento de recursos e funcionamento de mecanismos computacionais.

O código-fonte está dividido em módulos e arquivos responsáveis pelas diferentes funcionalidades do projeto, favorecendo a organização, a manutenção e o estudo das implementações.
